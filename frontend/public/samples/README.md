# Примеры импорта лицензионных участков (фигуры 1–7 из `data.txt`)

Файлы созданы по данным `data.txt` (все семь фигур: SVG = 1..7).
Все лежат в `frontend/public/samples/` — доступны по URL `/samples/<файл>`.

## Быстрый импорт по одному участку (кнопка «Примеры»)

В разделе «Проектирование» → группа «Территории» → кнопка **«Примеры»**
открывает список из **7 участков**. Клик по строке импортирует **только один**
выбранный участок (а не все сразу) из файла `licence-areas-1-7.json`.

## Формат нормализованных координат (рекомендуемый)

Нормализованные координаты `x, y ∈ [0..1]` переводятся в `lng/lat`
по bounding box карты. По умолчанию bbox — квадрат 1°×1° вокруг центра карты
(`60.009 N, 109.430 E`): `lng = 108.93 + x`, `lat = 60.509 − y`.

| Файл | Описание |
|---|---|
| `licence-areas-1-7.json` | **JSON со всеми 7 участками** — источник меню «Примеры» (клик грузит один) |
| `licence-areas-figures-1-3.txt`  | Markdown-таблица в стиле `data.txt` (SVG / Точка / X norm / Y norm) — 3 участка |
| `licence-areas-figures-1-3.csv`  | CSV: `area,point,x_norm,y_norm` — 3 участка |
| `licence-areas-figures-1-3.json` | JSON: `[{ name, points: [[xNorm,yNorm], …] }]` — 3 участка |
| `licence-areas-figures-1-3.geojson` | GeoJSON с **абсолютными** WGS-84 координатами (bbox по умолчанию применён) |

## Состав 7 участков (число точек)

`1: 9`, `2: 14`, `3: 9`, `4: 10`, `5: 9`, `6: 7`, `7: 5`.

## Как импортировать

1. Раздел **«Проектирование»** → группа **«Территории»** → кнопка **импорта** (иконка стрелки вниз).
2. Выбрать `.txt`, `.csv`, `.json` или `.geojson` — формат определяется автоматически.
3. Для `.txt`/`.csv`/`.json` создаётся **несколько участков** (группировка по `SVG`/`area`);
   для `.geojson` — один участок. **Разово импортируйте один участок** кнопкой «Примеры».

## Как задать точный bounding box

Если нужны реальные географические координаты (а не подстановка «±0.5° вокруг центра»),
bounding box задаётся в `frontend/src/features/map/importAreas.ts` — функция
`defaultBoundingBox()`. Либо можно импортировать сразу GeoJSON с абсолютными координатами.
