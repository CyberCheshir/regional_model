# Описание дизайна и фронтенд-архитектуры интерфейса моделирования

Данная директория содержит полную техническую формализацию дизайна из файла `design.png` для команды фронтенд-разработки в соответствии с требованиями `AGENTS/frontend developer.md` и предметными правилами `AGENTS/consultant.md`.

---

## 1. Структура документации

1. [**`components.md`**](./components.md) — Иерархия компонентов интерфейса, структура DOM-дерева, контракты props/emits и требования к состоянию (State Management).
2. [**`styles.md`**](./styles.md) — Дизайн-система: цветовые токены, CSS-переменные, типографика, оформление контролов (тумблеры, сегментированные кнопки, радиокнопки, плавающее модальное окно, бейджи статусов).
3. [**`icons.md`**](./icons.md) — Полный реестр векторных иконок для панелей навигации, дерева объектов, карточки инспектора и шаблоны inline SVG.

---

## 2. Обзор концепта интерфейса (по design.png)

Интерфейс представляет собой рабочее место инженера-моделировщика нефтегазового актива и состоит из четырёх функциональных колонок:

| Колонка | Ширина | Назначение |
|---|---|---|
| **Activity Bar** | 56px | Глобальная навигация: *Карта*, *Данные*, *Расчёты*, *Аналитика*. |
| **Управление элементами** | ~340px | Иерархическое дерево объектов добычи, площадных объектов и трубопроводов с быстрыми действиями (вызов диаграмм и переключение видимости слоев/объектов), тумблерами подписей и выбором подложки карты. |
| **Центральная карта** | Flex (1fr) | Интерактивная карта топографического плана со схемой расположения объектов, связями потоков, числовыми бейджами расхода (напр., `1,8 млн м³/сут`) и плавающим окном быстрой настройки диаграммы на карте. |
| **Инспектор объекта** | ~380px | Карточка выбранного объекта с левой панелью быстрых вкладок (паспорт, параметры, календарь, тренды, алерты), бейджем статуса (`● Работает`), чекерами готовности расчётной модели и перечнем исходящих физических и логических потоков. |

---

## 3. Дорожная карта реализации (Frontend Implementation Roadmap)

### Этап 1: Дизайн-токены и базовый Shell
- Внедрить CSS-переменные из `styles.md` в общие стили (`styles.css` / Tailwind / CSS-модули).
- Создать компонент `AppIcon` на основе шаблонов из `icons.md`.
- Реализовать 4-колоночный лейаут `AppShell` с фиксированным `ActivityBar` и адаптивными боковыми панелями.

### Этап 2: Панель дерева объектов и фильтров (Left Sidebar)
- Создать компонент дерева `ObjectTree` с поддержкой вложенных групп:
  - *Объекты добычи* (кусты, скважины).
  - *Площадные объекты* (УПН, ЦПС, точки поставки).
  - *Трубопроводы* (нефтепроводы, газопроводы, продуктопроводы).
- Добавить в каждую строку быстрые кнопки действий (иконка графика диаграммы и иконка глаза видимости).
- Добавить нижний блок настроек карты (тумблеры `ui-switch` для подписей и предупреждений, радио-кнопки подложки: Космоснимки / Топографический план).

### Этап 3: Картографический холст и плавающее окно диаграммы
- Отображение узлов с цветовой кодировкой предметной области:
  - Оранжевый: кустовые площадки (добыча).
  - Зеленый: объекты подготовки (УПН).
  - Фиолетовый: узлы учета и сдачи.
- Метки расхода на ребрах графа/трубопроводах.
- Реализовать плавающее окно `MapDiagramModal` с сегментированным контролом выбора флюида (`Нефть`, `Газ`, `Вода`) и переключателем диапазона лет (`Как на карте`, `Весь период проекта`, `Свой диапазон`).

### Этап 4: Правая панель инспектора объекта
- Вертикальный таб-бар с иконками переключения секций инспектора.
- Шапка объекта с хлебными крошками и бейджем статуса (`● Работает`).
- Блок валидации «СОСТОЯНИЕ МОДЕЛИ» с чекмарками (Система сбора, Профиль добычи, Результаты ГР).
- Блок связей «СВЯЗИ»: физические трубопроводы и логические потоки (передача флюида без физического трубопровода).

### Этап 5: Интеграция с API и предметной моделью
- Привязка выбранного узла графа к состоянию инспектора.
- Синхронизация видимости объектов дерева со слоями карты.
- Разделение визуального состояния UI и доменной модели согласно принципам `AGENTS/frontend developer.md`.
